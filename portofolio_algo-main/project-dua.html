Game 3D: FreeCam Builder

FreeCam Builder adalah game 3D sandbox berbasis Python yang dibuat menggunakan engine Panda3D. Dalam game ini, pemain diberikan kebebasan penuh untuk merancang dan menyusun bangunan dari berbagai pilihan warna balok menggunakan sudut pandang kamera terbang. Salah satu tujuan saya membuat game ini adalah untuk memahami cara kerja ruang 3D, manipulasi kamera bebas, penempatan objek koordinat grid, serta sistem penyimpanan data peta (save/load) melalui kode.

Berikut cara kerja game dan cara memainkan FreeCam Builder:

Cara Kerja Game :

  1. Dunia 3D dirender secara real-time menggunakan grid koordinat untuk penempatan balok yang presisi.
  2. Sistem kamera bebas (FreeCam) memperbarui posisi dan sudut pandang pemain di udara secara fleksibel.
  3. Pemain dapat memilih berbagai variasi warna balok untuk menyusun struktur bangunan sesuai kreativitas.
  4. Data struktur bangunan yang telah dibuat dapat disimpan dan dimuat kembali melalui file data peta (my_map.dat).

Cara Bermain FreeCam Builder:

  1. Gunakan tombol kontrol navigasi (W, A, S, D / tombol arah) untuk menggerakkan kamera terbang menjelajahi area.
  2. Arahkan dan miringkan sudut pandang kamera untuk melihat area pembangunan dari berbagai perspektif.
  3. Pilih warna balok yang diinginkan, lalu pasang atau hapus balok untuk mulai membangun.
  4. Gunakan tombol pintasan Save/Load untuk menyimpan progres dunia ke dalam file atau memuat ulang bangunan yang sudah ada.
